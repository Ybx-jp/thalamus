| 2026-07-29 | **Cursor sessions distill, and a transcript that cannot carry evidence floors the whole session rather than reporting a clean check.** `harness/cursor_transcripts.py` produces the same `TranscriptFacts` the Claude Code reader does, so extraction, merging and provenance are unchanged; `thalamus extract --harness cursor` sweeps the sessionEnd log, scope resolved per-session ledger-first. Three structural gaps are carried explicitly, never inferred: no tool results (so `ingress_verifiable=False` and `apply_ingress_floor` floors every claim, stamped `transcript-ingress-unverifiable`), no message ids (anchors are positional `cursor:msg:<row>`), no timestamps or cwd (both from `pins.jsonl` and the sessionEnd log). See [05](05-trust-model.md), [07](07-harness-integration.md), lab/028. | Cursor excludes tool outputs from transcripts deliberately, because they can be very large (Cursor staff, forum 157311). That breaks docs/05's floor at two of its four layers: layer 1 collects the verbatim external text and layer 3 forces any claim echoing it to tier-2 **regardless of the model's mark** — the layer no prompt content can lift. Distilling naively would have left only layer 2, the layer docs/05 explicitly does not trust, while the code path reported success. The real defect was narrower and worse than a missing defence: an empty `external_texts` meant "nothing was fetched" on Claude Code and "we cannot know" on Cursor, with nothing distinguishing them — an absence indistinguishable from a negative. Flooring whole is heavy-handed by design; it takes the trade the floor already prices (tier-2 first-party memory informs, and costs nothing but emphasis) at the one moment the cheap mechanical check is unavailable, and it makes out-of-band capture the way to earn tier-1 back rather than something to remember. Extraction is a later sweep rather than a sessionEnd action because Cursor is not documented to flush before firing the hook (open request to fsync or add `transcript_ready`; staff answered "no implementation timeline"), and a truncated distillation is a corrupted memory rather than a missing one. Backfill works at all only because the sessionEnd hook has been logging `transcript_path` with `distilled: false` since the port shipped. `render_digest` gained a `role` fallback and user text-block rendering — one renderer, two dialects — with a regression test pinning Claude Code digests byte-identical. |

## Bootstrapping memory

The prior project's memories were deliberately **not** carried over; memory is being
re-derived from this machine's own session transcripts. See
[10-evidence-archive.md](10-evidence-archive.md).

**Both stages are built and have run over the full corpus** (2026-07-15). Stage 1
(`thalamus bootstrap`): transcripts retained in the immutable, content-addressed archive
at `~/.thalamus/archive/`; `Source` / `Session` / `Artifact` / anchored `TOUCHES` derived
from tool-call records with no model in the loop — 64 sessions, zero contract rejections.
Stage 2 (`thalamus extract`): claims and threads extracted via headless `claude -p`,
merged into the deterministic layer, chronologically so threads resolve forward in time —
**63 sessions, 1,089 claims, 196 threads (45 resolved, 90 continued by later sessions),
~$30 of model time.** The graph now holds ~2,459 vertices and ~4,918 edges. Memory is
live in this repo: the MCP server and SessionStart/SessionEnd/PostToolUse hooks are
installed, so new sessions recall at start, distill themselves at end, and leave
retrieval traces for M2. See [10](10-evidence-archive.md) for what the first full run
taught, including the finding that content-addressed claim convergence never fired.

Allowlisted: `stepmania-chart-generator` (69 transcripts) and `thalamus`. **Not** the
home-directory sessions — they contain résumé/personal history and the media-server work,
which carries VPN credentials.

Ordering was load-bearing, and it is why M0.5 came first: bootstrapping against the old
schema would have produced a corpus with no provenance, tier, or scope — the retrofit
[05](05-trust-model.md) calls the canonical mistake, reached by a different road.
