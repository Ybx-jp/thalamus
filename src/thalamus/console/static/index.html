Roster

Per-session restart and close live on the session's own row. Roster sync is idempotent backfill: it adds windows the pin ledger expects and touches nothing that is already running.

Cursor distillation

Cursor sessions don't distill themselves — a swept session becomes memory, an unswept one never existed. Writes to the graph and costs a model call per session; already-extracted ones are skipped.

Launch posture

What a newly launched session starts with. Flags ride the argv, so this cannot reach a running window — restart one to adopt it. A posture looser than the default can be given a lifetime, and reverts on its own if you give it one.

Extraction

Which CLI calls a model on your behalf, and on which model. Distillation turns an ended session into memory — one pass per session, nothing waiting on it. Ingestion reads a procured document, one pass per chunk, so a single paper can cost what a day of distillation does. Neither needs to run on the same allowance as your interactive sessions. Both take effect on the next pass — running windows are unaffected, because the choice is read when the pass starts, not when the session launched.
